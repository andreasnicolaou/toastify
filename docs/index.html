Security & notes

  • The title, the action label and the message are inserted as text. Only isHtml: true renders HTML. Never use isHtml with untrusted text: the library has no sanitizer, so sanitize it yourself or leave isHtml off.
  • CSP friendly: no <style> element, no style attribute, no eval. Load dist/styles.css yourself.
  • Errors and warnings use role="alert"; the rest use role="status".
  • Call toast.destroy() to remove every container, timer and listener (the Clear all button does).
